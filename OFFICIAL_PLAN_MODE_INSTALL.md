# MomoPro AI v0.95C2 — Official Plan Mode Installation

## Architecture

Use two indicators on the same TradingView chart:

1. **MomoPro Stable Phase 5.6** — unchanged. It continues running every existing feature, including entries, grading, adaptive learning, MTF logic, support/resistance, lifecycle, exit engine, trailing stop, visuals, and alerts.
2. **MomoPro Official Plan Validation v0.95C2** — imports the strategic plan generated by MomoPro AI and validates it against live candles.

The scripts are separate because TradingView does not let one Pine script access another script's private variables, and merging the integration into the full Phase 5.6 script previously exceeded Pine's main-body limit.

## TradingView setup

1. Deploy the updated app files.
2. Open a ticker in MomoPro AI and generate or load its Official MomoPro Plan.
3. Open **Live Chart → TradingView Bridge → Official Plan Mode**.
4. Copy the entire one-line Official Plan Packet.
5. In TradingView, keep the original Phase 5.6 indicator on the chart.
6. Create a new Pine indicator using `MomoPro_Official_Plan_Validation_v0.95C2.pine` and add it to the same chart.
7. Open its settings.
8. Turn on **Enable Official Plan Mode**.
9. Paste the packet into **Official Plan Packet**.
10. Leave **Validate Timeframe** off for the first test.
11. Confirm the symbol, entry, stop, targets, scores, and status panel match the app.

## Expected first test

- Before price enters the official entry zone: `WAITING FOR ENTRY`
- Inside the entry zone without complete confirmation: `ENTRY AREA — WAIT`
- Inside the entry zone with all required live confirmations: `ENTRY CONFIRMED`
- Above the maximum chase or too far above EMA21: `TOO EXTENDED`
- At or below the official stop/support invalidation: `PLAN INVALIDATED`
